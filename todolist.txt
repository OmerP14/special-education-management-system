Build a complete, production-grade Settings module for the Special Education Management System.

This is not a placeholder screen.

The Settings area must become a real control center where institution-wide configuration is managed and actually affects the application.

Important:

- Do NOT implement the full roles/permissions system yet.
- However, design every settings section so role-based access can be added cleanly later.
- Add permission-ready metadata and section boundaries.
- Keep current mock-store architecture.
- Do not start Supabase integration.
- Do not break existing working modules.
- Do not duplicate business rules already implemented elsewhere.
- Reuse current dynamic Education Types implementation.
